# BlockFace 品牌与界面设计规范

本规范定义了 BlockFace 的视觉语言与设计系统标准，代码实现（`src/styles/tokens.css`）须与本规范保持严格对齐。

---

## 1. 核心设计原则

1. **8px 积木网格**：所有尺寸、间距、控件高度与图标均基于 8px 基础网格或其半数（4/8/12/16/24/32/40px）。
2. **全平涂硬边 (Flat & Hard-edged)**：杜绝圆角、渐变与多层投影。界面层次仅依靠 1px 细线、4px 语义色条和色块对比呈现。
3. **纯 CSS 像素图标**：严禁使用 Emoji、位图图示或外部图标字体。所有图标均由纯 CSS 矩形方块拼装，色彩随上下文 (`currentColor`) 联动。
4. **像素优先采样**：皮肤贴图严格使用最近邻渲染（`image-rendering: pixelated`），保持 Minecraft 经典的硬边像素质感。
5. **状态可见性**：信息状态严禁仅依靠颜色区分，必须伴随明确的文本提示或图例标注。

## 2. 颜色系统与设计令牌

### 2.1 基础调色板

| 令牌名 | 色值 | 说明 |
| :--- | :--- | :--- |
| `--ink` | `#14110F` | 墨黑：正文文字、主边框、选中激活态 |
| `--ink2` | `#5F584E` | 次墨：辅助说明文字、次要标签 |
| `--line` | `#CFC8BA` | 浅边框线：卡片分割线、次要边框 |
| `--paper` | `#F2EFE6` | 纸色：页面与主容器背景底色 |
| `--rail` | `#F7F5EF` | 侧栏底色：左右侧面板背景 |
| `--white` | `#FFFFFF` | 纯白：顶栏底色、卡片及输入框背景 |
| `--stage` | `#232019` | 画布工作区深色底色 |
| `--stage-line` | `rgba(242,239,230,.075)` | 画布 8px 细网格线 |
| `--stage-major`| `rgba(242,239,230,.16)`  | 画布 40px 粗网格线 |

### 2.2 语义色条映射

每个区块左侧均带有 4px 垂直色条，用于标识功能属性：

| 语义色 | 色值 | 承担职责与功能区块 |
| :--- | :--- | :--- |
| **草绿 (`--grass`)** | `#4E9A3D` | 皮肤资产：内置皮肤、已载入皮肤、图层列表、主操作按钮 |
| **黄金 (`--gold`)** | `#E0A526` | 联网查询与数值：正版账号 / MUA 联合认证查询、位置/尺寸/旋转滑块；以及必须抬头看见的提醒 —— 预览底图横条的色条与状态栏「预览」徽标 |
| **青色 (`--cyan`)** | `#3FA9AF` | 本地与开关：上传皮肤、帽子层开关、水平翻转 |
| **红石 (`--red`)** | `#C8402F` | 直改与销毁：URL 载入、删除/重置、选中控制柄图形 |
| **深红 (`--red-ink`)** | `#9E2E1E` | 警告与错误文字（保证 ≥ 4.5:1 对比度） |

## 3. 字体与排版阶梯

```css
--sans: "Segoe UI", system-ui, -apple-system, "Microsoft YaHei", sans-serif;
--mono: "Cascadia Mono", Consolas, "SFMono-Regular", Menlo, monospace;
```

| 应用场景 | 字号 / 字重 | 字体族 |
| :--- | :--- | :--- |
| **品牌标识 Logo** | 17px / Bold | `var(--mono)` |
| **区块标题 (h3)** | 13px / Bold | `var(--sans)` |
| **正文、按钮、输入** | 13–14px / Regular–SemiBold | `var(--sans)` |
| **数值、坐标、规格** | 12–13px / Bold | `var(--mono)` |
| **辅助说明、状态栏** | 12px / Regular | `var(--sans)` |

> **排版红线**：最小字号不得低于 12px；正文文本对比度须严格满足 WCAG AA 级（≥ 4.5:1）。

## 4. 间距与核心控件尺寸

- **顶栏高度**：60px（底部 1px `--ink` 细线）
- **左右侧栏宽度**：292px
- **状态栏高度**：32px
- **控件高度**：顶栏按钮 34px，面板按钮 / 输入框 32px
- **开关轨道**：40×20px，方块滑钮 16×16px
- **滑块轨道**：8px 高度（内嵌刻度虚线），手柄为 14×14px 正方形方块
- **图层列表项**：42px 高度，左侧 4px 激活色条

---

## 5. 画布与交互手柄

- **画板边界**：1px 细线描边；无底图时呈现棋盘网格。
- **选中外框**：沿图层边界先铺 3px 纸色描边、再压 1px `--ink` 墨线（视觉上即「1px 墨线 + 1px 外扩纸色偏移」），保证在任何明暗底图上均清晰可见。
- **四角缩放手柄**：11×11px 红色方块 + 1px 细边。
- **旋转控制柄**：2px 红色引线 + 12×12px 纸色旋转方块（中心内嵌红色方孔）。
- **手柄坐标系**：以上尺寸均以**屏幕像素**为准，画在工作区视口层的覆盖画布上（不随画板缩放而变大变小），按 CSS 像素取整、1px 细边走 +0.5 半像素对齐，保证任意缩放倍率下边缘锐利。
- **极小头像微缩**：头像在屏幕上的显示尺寸小于 28px 时，四角手柄与旋转方块按同一比例等比微缩（四角不小于 6px，旋转方块不小于 7px，中心方孔不小于 3px），避免四个角柄在极小尺寸下互相覆盖；显示尺寸 ≥ 28px 时恒为标准尺寸。微缩是极小尺寸下的刻意例外，属屏幕像素级取值，不受 §1 的 8px 布局网格约束。

---

## 6. 设计规范禁用项

- ❌ 禁止使用 Minecraft 官方商标、Logo 或官方字体。
- ❌ 禁止使用 Emoji 充当功能图标。
- ❌ 禁止添加圆角（唯一例外为系统辅助聚焦环 :focus-visible）、渐变或模糊扩散阴影。
- ❌ 禁止出现小于 12px 的文字。
- ❌ 禁止单独通过颜色区分状态，必须伴随文字或语义图标。
