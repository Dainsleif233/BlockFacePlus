# BlockFace+ · 功能与交互规格说明

本文档定义了 BlockFace+ 核心功能的规格定义与交互行为边界。

---

## 1. 产品定位与信息架构

BlockFace+ 是一个运行于现代 Web 浏览器的 Minecraft 头像贴图与图片合成工具：离线使用时是纯前端应用——上传照片/截图作为底图，在上面自由贴上一个或多个 Minecraft 像素头像或通用头像图片，并导出为 PNG；也可以把画布一键发布为「协同房间」，让拿到链接和密码的人在线共同编辑。

### 1.1 界面三栏架构
- **顶部操作栏 (TopBar, 60px)**：品牌 Logo（BlockFace+）、打开图片、复制到剪贴板、导出 PNG、撤销/重做。
  - 离线模式下提供「共同编辑」发布入口；房间内「打开图片」（换底图）仅管理员可见。
  - 房间模式下显示角色徽章（编辑者/管理员）、待提交计数（「N 个未保存」）与「完成」提交按钮；管理员另有删除房间按钮（需确认两次）。
- **左侧素材栏 (SkinPanel, 292px)**：
  - 内置经典皮肤展示（Steve / Alex，支持预加载与真实渲染）
  - 正版账号 ID 查询（支持单条或多个账号空格/换行分隔批量查询）
  - 本地皮肤文件上传（标准 64×64 / 64×32 PNG 皮肤，支持拖放/多选）
  - 外部图片 URL 导入（自动规范化 http 到 https，内置超时与三级跨域回退）
  - 本地头像图片上传（PNG / JPG / WebP 等通用图片，直接贴图，支持拖放/多选）
  - **已载入素材管理**：已注册素材列表展示、单张删除（悬浮显示垃圾桶图标）与一键清理闲置素材（带未引用与撤销历史栈引用双重保护）
- **中间画板工作区 (StageCanvas)**：
  - 无底图时提供棋盘网格与导入引导
  - 底图与头像图层实时 Canvas 合成渲染（点击任意空白处或图层自动聚焦，支持键盘操作）
  - 选框手柄（四角缩放方柄、顶部旋转旋钮）、微调指示条与浮动坐标提示；**协同编辑者模式下只绘制选中框，不渲染旋钮与手柄**（布局冻结，避免「拖得动却没反应」的误导）
  - 底部提示条随角色切换：编辑者显示「布局已锁定 · 左侧选皮肤给选中的头像换装」
- **右侧属性栏 (InspectorPanel, 292px)**：
  - 选中头像预览（支持就地编辑图层名、实时跟随水平翻转镜像；协同编辑者下图层名只读）
  - 正面第二层（帽子层）开关（通用头像图片自动禁用帽子层并标为「无」）与水平翻转开关
  - 坐标 (X, Y)、尺寸、旋转角度、不透明度精确滑杆与微调输入（协同编辑者下整体隐藏）
  - 居中、铺满、重置快捷操作与选中图层快捷操作（复制、删除，删除带二次确认超时机制）（协同编辑者下隐藏）
  - 图层堆叠列表（调整层级、显隐切换、选择图层、缩略图跟随镜像翻转、支持 `Alt+↑/↓` 快捷键；协同编辑者下隐藏拖动把手与显隐按钮，仅保留点选）
  - **协同编辑指引**：布局冻结时面板显示固定指引（点选画布头像 → 左侧换肤 → 顶栏「完成」提交），并实时显示待提交头像数
- **覆盖层组件**：
  - **房间门禁 (RoomGate)**：`?room=` 模式下的密码门禁、载入遮罩、过期与错误态四块界面
  - **发布对话框 (PublishDialog)**：选过期时间 → 创建房间并直传底图 → 展示专属链接与两把密码（只显示这一次）
- **底部状态栏 (StatusBar, 32px)**：
  - 画布物理尺寸、视口缩放比例、当前图层计数与隐私合规指示（离线模式 "本地计算 · 图片不上传"）

## 2. 核心交互行为规范

### 2.1 底图与剪贴板智能识别
- **载入方式**：支持点击「打开图片」、文件选择、拖拽图片至窗口任意区域、或从系统剪贴板粘贴 (`Ctrl+V`)。
- **剪贴板意图推断**：
  - 若当前画布**无底图**：粘贴图片自动识别并设为画布底图，自动适配文档分辨率；
  - 若当前画布**已有底图**：粘贴图片自动转为贴纸图层载入素材库并贴至画布中央，不破坏现有底图。
- **分辨率与边界**：画布物理尺寸自动与底图等宽等高对齐；更换底图时不重置现有头像图层，只更新画布边界。
- **协同差异**：房间内更换底图仅管理员可用，走预签名直传通道（见 product-facts §4.4）。

### 2.2 皮肤添加与图层控制
- **单选与换皮**：当选中某个已有图层时，点击新皮肤为“当前头像换肤”。
- **新增图层**：点击素材卡片添加，或通过批量输入（账号列表、多选文件）一次性生成多个图层，新头像按方阵平铺排列。
- **交互手势**：
  - 拖拽头像主体：在画布上移动位置；
  - 拖拽四角红柄：等比缩放头像尺寸；
  - 拖拽顶部引线旋钮：旋转头像角度；
  - 滚轮：光标位于头像上方时滚动缩放，按住 `Shift` 滚动旋转；
  - 键盘微调：方向键平移 1px，按住 `Shift` 平移 10px；快捷键 `[` / `]` 调整图层层级；
  - 水平翻转：支持一键翻转，属性栏预览与图层列表缩略图实时保持同步。
- **协同差异**：编辑者模式下上述布局手势整体冻结（画布手势、属性滑杆、快捷键、图层列表四路拦截），仅保留「点选头像 → 换肤」；管理员不受限。

### 2.3 协同房间 (Collab Room) 体系
- **发布**：离线画布一键发布成协同房间。过期时间只认 3 / 7 / 14 天（默认 7）；发布成功后一次性展示专属链接、编辑密码（8 位）与管理员密码（12 位），三样只显示这一次；发布者点「进入房间」自动持有管理员权限。
- **专属链接**：`?room=<房间号>`；房间号为 6–64 位 URL 安全字符，密码本身不进链接。
- **门禁与身份**：凭密码进入，密码决定角色——编辑密码进编辑者，管理员密码进管理员；同一链接不同密码不同身份，顶栏以徽章明示当前角色。
- **编辑者边界**：只能修改头像皮肤。位置、尺寸、旋转、层级、显隐、增删与改名全部冻结；改动累积为「待提交」计数（撤销回基线即时归零），点顶栏「完成」即差量提交（只发改动过的行与字段，改多少都不设条数上限）；某条被别人抢先改动时只有那一条留在「待提交」并给出提示，其余条目照常落盘。
- **管理员能力**：全量编辑（挪动/缩放/旋转/增删/显隐/改名）、更换底图、删除房间（二次确认）；提交按域带版本凭证（改动布局只比布局戳、换内容只比内容戳），冲突只影响那一条，不会把整次提交打回。
- **会话**：密码只存 sessionStorage（`blockface-plus.room.<房间号>`），刷新不丢、关标签页即清空，绝不写 localStorage。
- **生命周期**：到期后访问房间直接看到「房间已过期」并停留原地；过期房间连同全部内容被清理。删除房间为管理员专属操作。

### 2.4 撤销与重做体系
- **历史记录栈**：图层增删、移动、缩放、旋转、属性变更均计入撤销历史。
- **视口与文档解耦**：纯视口缩放与视口平移不污染撤销记录。
- **素材生命周期与历史栈一致性**：在清理闲置素材或单张删除素材时，若该素材在 `past` 或 `future` 撤销/重做栈中有被引用，则受保护不被清理，确保执行 `Ctrl+Z` 后图层材质完好无损。
